# Montclair-WorldBuilding

Worldbuilding-Wissensbasis für die Fantasy-Welt der Dynastie Montclair (Hintergrund für einen Minecraft-Server).

- **`Kanon/`** — strukturierte Fakten (Reiche, Personen, Weltregeln, Religion)
- **`Werke/`** — die eigentliche Prosa (Königsbücher, Chroniken, Geschichten)
- **`00-Meta/`** — Zeitleiste, Glossar, offene Fragen, Stilrichtlinien

Projektkontext und Arbeitsweise für die KI-gestützte Weiterarbeit: siehe [CLAUDE.md](CLAUDE.md).
